# Screenshots Directory

This directory stores visual documentation for the **Smart Text Intelligence** application.

## How to Capture and Save the Screenshot

1. Launch the Streamlit application in PowerShell:
   ```powershell
   streamlit run app.py
   ```
2. Open your web browser at `http://localhost:8501`.
3. Select or enter sample text and click **"Classify Text"** to display the predicted category, confidence score, and probability distribution.
4. Take a screenshot of the browser window:
   - On **Windows**: Press `Win + Shift + S`, select the browser window area, paste it into Paint or an image editor, and save as `demo.png`.
   - Or use the browser built-in developer tools screenshot tool.
5. Save the image file directly in this folder:
   ```
   screenshots/demo.png
   ```
6. The image will automatically render in the main `README.md`.
